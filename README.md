# Placement Preparation

A structured C/C++ placement preparation repository documenting my learning journey through core programming fundamentals, problem solving, and DSA practice.

This repository is designed for:
- students preparing for campus placements and coding interviews,
- beginners building a strong C++ foundation,
- learners who want lecture-wise and practice-oriented progression.

## Repository Overview

| Section | Purpose |
|---|---|
| [Apna-College-CPP](./Apna-College-CPP/) | Course-aligned C++/DSA learning material and weekly progression |
| [DSA](./DSA/) | Beginner-to-intermediate C++ practice programs and pattern/problem drills |
| [Fight with DSA](./Fight%20with%20DSA/) | Lecture-style DSA journey with intro, flowchart, functions, and pattern-focused content |
| [LeetCode](./LeetCode/) | LeetCode-oriented preparation notes/workflow |
| [Other](./Other/) | Additional C-language and miscellaneous practice material |

## How to Use This Repository

1. Pick a section from the overview table.
2. Follow lecture/week order where available.
3. Compile and run individual C/C++ files locally.

```bash
# Compile a C++ file
g++ filename.cpp -o app
./app
```

```bash
# Compile a C file
gcc filename.c -o app
./app
```
